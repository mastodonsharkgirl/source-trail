# Source Trail

Source Trail is a private-preview, browser-local evidence retrieval experiment.
It searches an authored fictional source pack and returns exact passages; it
does not answer questions, assess truth, or send a visitor's notes or vectors
to a service. Model assets download only after a visitor requests local search.

Task 1 supplies the bounded corpus, lexical and vector ranking, worker protocol,
same-host asset preparation, and a reproducible evaluation. Task 2 owns the
visitor-facing source desk and browser release checks.
